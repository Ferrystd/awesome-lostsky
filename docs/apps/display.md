# Display 应用

Display 提供团队的公开展示数据。请求需要能够从域名确定团队，但不要求用户登录。

## 业务职责

- 返回团队公开资料，包括基本信息和公开介绍。
- 返回允许公开展示的成员列表。
- 返回单个公开成员的资料和岗位信息。

公开接口只返回展示服务筛选后的字段，不能代替 Team 应用中的成员管理接口。

## 鉴权边界

- 不经过 `JwtAuth`、`Context` 或成员访问中间件。
- 团队由全局应用解析和路由流程写入请求上下文。
- 数据可见性由 `Display` 服务统一控制。

## 接口契约

具体路径、查询参数和响应结构见 [`display.openapi.json`](../openapi/display.openapi.json)。
