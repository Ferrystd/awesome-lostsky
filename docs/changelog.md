## 未发布（目标 v0.1.9）

## v0.1.8（2026-08-26）

### 新增

- 新增团队上下文 Weibo 应用、第五个共享应用入口，以及账号绑定、图片上传、超话单次操作、随机间隔任务和最近 30 天执行日志。
- 移植 Weico 6.4.7 动态 `from`、本地 `s`、图片与严格错误分类，外部写请求保持单次调用且不自动重试。
- Weibo 任务新增“每日签到”类型，复用现有队列、候选账号、Ability、登录阻塞和防重日志，每个服务端自然日最多尝试一次超话签到。

### 变更

- 微博工作台侧栏完整对齐 Team 的品牌、分组、箭头、激活态与身份切换结构；团队概览升级为聚合下一次执行、账号健康、任务状态、异常记录和连续工作入口的调度 Dashboard，个人概览保留共享工作台主视觉；无 Weibo Ability 或态势读取失败时导航与全部页面仍保持可达。
- Weibo 取消业务 Permission 门槛；无 Ability 时仍可使用全部页面、账号、媒体、任务配置与日志，仅远端发帖/点赞/评论和任务开启/恢复要求 Weibo Ability。
- Weibo Ability 仅保护远端写操作和任务执行；页面、账号管理、图片准备、任务配置与日志读取在 Ability 缺失时继续可用。
- Weibo 缺少 Ability 时不再常驻显示警告或提前报错，远端写入及任务开启/恢复按钮保留可点击的禁用态并在点击后说明原因；手动操作移除确认词输入，仍保持一次点击最多一个远端请求且不自动重试。
- Weibo 点赞与评论改为填写微博正文页链接，由服务端解析目标 ID；首版移除从已有帖子读取图片的页面入口和 API。
- Weibo 新建与编辑任务页改用后台公共表单分区、字段和操作组件，按执行安排与任务内容组织自动发帖或每日签到字段，并补齐读取失败状态。
- 开发阶段微博凭据明文入库，但从模型序列化、API、业务审计和运行日志排除；统一外部写操作最小日志与 30 天清理方法。

## v0.1.7（2026-08-22）

### 变更

- Admin 侧栏新增“团队能力”表单，可仅凭准确 slug 开通、调级或续期 Ability，不要求读取全量团队；团队详情预填入口和独立审计记录继续保留。
- 统一 Vue 前端站点的 Nginx SPA 深链接回退规则，并明确 API、公共资源与文档站不得使用该规则。
- Transaction 接单邀请会按是否需要填写字段显示对应的接受操作。
- 服务核销资料改为按最小步长逐份保存，团队可逐份核对并通过或驳回，顾客可查看商品内含服务。
- Shop 核销字段迁到服务定义，同一商品的不同服务可分别配置并随服务资料原子保存。
- Transaction 接单收口到任务详情，支持按步长部分接单，并统一任务状态、资料和历史展示。
- Transaction “我的接单”改为三段任务队列，统一服务、顾客、核销资料与操作层级。
- Transaction 经营统计支持日周月、流水趋势、人员排行和服务端排序分页，并补充新增预存。
- 人员统计按成交与核销计算接发单及业绩，权益包多次核销不重复计算发单。
- Transaction 根入口默认进入团队概览，团队流水迁入独立的 `/transactions` 业务入口。
- Account 身份页左上角改为返回进入前记录的安全页面；领取、切换或放弃身份后保持在当前页，支持连续切换，完成后再主动返回。
- Transaction 流水详情中，不存在的发单人或客服改为以短横线表示，不再显示为未知人员。
- Transaction 个人入口统一为流水、接单、客户和权益下发；流水登记迁入个人页并自动填充业务归属。
- “我的客户”合并归属与协作发单关系，同一客户仅展示一次并保留关系标记。
- 使用手册新增名词解释，各应用同步精简实体、权限和能力等术语文案。
- Team 团队概览与个人工作台的「使用文档」直接打开用户指南站，不可用指标以气泡提示说明原因。
- Admin 体验活动的保存、发行、验码等操作统一以提示反馈错误。

## v0.1.6（2026-08-14）

### 新增

- Transaction 新增“赋予客户权益”任务页，可从 Shop 服务套餐商品直接交付独立权益且不创建订单。
- Shop 个人工作台新增“我的服务 → 我的权益包 → 我的卡活动/卡密 → 我的商品”完整链路；服务、权益包和卡活动支持团队公用或 Entity Owner，并新增独立的 `shop.product.self.package.reprice` 权限保护公用服务金额。
- Transaction 个人工作台新增“权益赠送”列表，入口无需业务 Permission 即可查看当前 Entity 直接赠送的全部权益；“赠送权益”按钮及任务受 `service.entitlement.grant` 保护，只能操作当前发单人接待的客户。
- 新增 Shop Ability 与默认关闭的商城总开关，公开购买链路统一实时关闸。
- 有限期 Ability 到期后自动降级、通知；Shop 失效时自动关闭商城。
- 服务接单支持无时限指定邀请、客户主动取消、公开召唤、并发抢单和主动退回公开池。
- Team 新增受 `team.audit.read` 保护、支持双重归因的审计日志。
- 系统运行日志统一记录请求、异常、命令和短信故障，并支持脱敏轮转。
- Shop 个人工作台支持本人商品与权益资源管理，客户可在 File Ability 内自助上传。
- OSS 支持统一缺图原图、图片 404 重定向和匿名只读发布命令。

### 变更

- Transaction 团队工作台的“服务核销”入口、列表和详情统一要求 `service.redemption.read` 或 `service.redemption.manage`，个人“我的核销”继续按本人范围开放。
- Transaction 个人工作台的相关流水、我的业绩、我的核销、客户协作和权益赠送统一开放本人范围读取；`transaction.read`、`transaction.report.read` 等 Permission 只控制 Team 全量资源。
- 服务接单池留空改为“不限”，服务列表直接显示具体接单人或“不限”，服务编辑统一为单次保存，并将 Entity 下拉收敛为带类型、名称和 slug 的公共选择器。
- 服务定义与团队默认设置移除“数量精度”，数据库与接口一并删除独立精度字段，服务及权益统一根据各自的最小核销步长自动推导。
- 修复团队“服务履约”默认分成比例以字符串穿透管理接口，导致新建服务修改价值或成本后人员分配仍为零的问题。
- Shop 商品编辑页把核销字段合并到正文，并统一通过上架状态控制公开展示；标题区仅保留独立的前台预览按钮。
- Shop 服务编辑页移除重复的顶部停用按钮，改用统一的单页面主操作“预览商品”在新标签页打开商城前台；服务停用继续由表单内的启用状态控制。
- Shop Ability 缩小为公开商城开关边界；后台商品维护不再依赖该 Ability，并新增手动赋予权益的独立流水 TeamSetting。
- 服务权益支持计量额度、并行履约、接单人分配、加价确认和分成设置。
- 静态站可再生产物改由发布机从不可变标签构建，不再纳入源码仓库。
- 身份领取和虚拟实体代操作启用新权限键，工作台统一展示禁用原因。
- 后台表单与布尔设置统一复用封闭组件，并以源码和 DOM 测试验收。
- 商品、资料和 Markdown 图片支持本地上传，File Ability 统一限制总容量。

### 修复

- 修复 Transaction 根路由以不完整前缀匹配吞掉发单绑定、余额和流水子路由，导致业务页面收到错误响应并进入页面错误状态的问题。
- 服务定义的人员分配会随单位价值与成本按团队比例重算，团队分配改为只读余额并由服务端强制校准，避免金额求和不一致。
- 后台页面标题区主操作统一为强制图标和 8.5rem × 44px 紧凑等宽尺寸，移动端保持靠右、仅在容器不足时收缩；权限或业务条件禁用时保留一致的灰绿色主色降权与原因说明。
- 修复上传响应、媒体回填、Shop 权益表单、候选缓存和读取状态问题。
- 修复 Team 团队概览与个人工作台入口被误设为等宽：宽屏恢复左宽右窄单行层级，窄屏保持全宽。
- 统一 Team 概览入口与设置保存布局，实体公开设置改为原子保存。
- 修复履约中 Ability 失效、发单分成、审计目录和 OpenAPI 请求体问题。

## v0.1.5 (2026-08-07)

### 新增

- 权限域完成开发期硬切换：实体创建、维护和字段管理使用 `team.entity.*`，跨应用代执行使用 `identity.virtual.*.act`，Chat 权限目录仅保留聊天能力；升级补丁迁移并删除旧权限键，不提供别名兼容。
- Team、Shop 与 Transaction 新增个人/团队工作台，六个工作台固定以概览为首项并支持双向切换。
- Team 个人工作台支持 Team、成员与虚拟实体维护资料和本人对象字段，并查看角色与有效权限。
- Shop 新增商家后台，统一管理商品、订单、服务权益、三类卡密及核销交付。
- Transaction 支持服务收款、分阶段核销及核销自定义字段。
- Team 与 Admin 新增 Ability 权益、体验活动及卡密预检和兑换管理。

### 变更

- 保留 Team 团队概览，重做其余五个概览并统一四应用导航、业务卡片、范围说明和双向切换。
- Account 实体自管迁入 Team 个人工作台，客户回归商城客户中心，旧深链按身份安全跳转。
- Shop 与 Transaction 个人查询强制按当前 `acting_entity` 隔离；能力缺失时入口保留且不发业务请求。
- 成员入离职支持申请字段、邀请来源、资料转存、自助离队、管理员离职及原身份复职。
- Display 新增主页文案与公开实体目录；公开文档支持标签和主页分组，后台统一响应式交互。
- 团队角色新增高级范围权限；父级 Permission 自动覆盖当前及未来的同前缀业务权限。

### 修复

- 修复实体委托、动态 Permission 来源和角色实体选择不一致，并保留有效权限的真实记录语义。
- 修复工作台导航跳动、间距与禁用入口错位，权限、Ability 和 TeamSetting 原因统一可见。
- 修复 Shop 父级 Permission、个人核销权限、客户深链及迁移后文档契约不一致。

## v0.1.4

### 新增

- 展示页与商城新增邀请 `ref` 持久传播：首次建立客户身份时登记同团队邀请实体，客户二次转发和跨页面访问不丢失来源。
- 团队工作台新增客户列表与详情，支持归属范围读取、资料/归属/封禁管理和 Chat 对话入口；新增 `team.customer.read`、`team.customer.manage`。
- 商城顾客中心允许客户本人查看、修改或清空服务归属；流水统计新增归属业绩和当前实体邀请链接。
- 收紧团队实体基础目录：Customer 始终要求 `team.entity.read`，既有未公开虚拟实体默认转为团队内隐藏；新增 `team.document.read` 控制文档全量读取与概览计数，无权限时文档卡显示进入箭头。
- 修复团队文档阅读页未兼容分页列表详情响应而显示“未命名文档”和空正文的问题，并重整阅读层级、元信息与加载/错误/空正文状态。
- 实体与成员新增独立的团队内可见状态；`team.entity.read` 与 `team.member.read` 调整为全量读取权限，基础目录继续向所有团队 Entity 提供内部可见内容。
- 团队新增通用访问快照和访问感知概览接口，概览固定展示实体、成员、文档和通知，并支持单指标降级。
- 团队工作台新增“查看公开主页”，实体详情新增团队内可见控制和已公开实体直达入口。
- 团队工作台在顶栏、概览、实体与成员列表及详情中新增上下文对话入口，可直接进入当前团队消息页并预选聊天对象。
- 新增独立的 Admin 平台治理应用，覆盖平台 RBAC、用户与团队封禁、会话撤销、集中审计、系统状态、CLI 超级管理员自举，以及桌面和移动端管理界面。
- 新增 `team.notice.read` 与通知能力接口，分别控制 Team 共享站内通知入口并向前端返回站内通知查看、通知发送和默认收件箱能力。
- 新增 `certificate:update` 命令，以一张多 SAN Let’s Encrypt 证书统一更新全部 Nginx 前端/API 域名和 OSS 自定义域名，并支持 Certbot 续期钩子。
- 新增 `team:grant-ability` 命令，支持通过服务器终端为指定团队幂等授予、更新或恢复 Ability。
- 公开实体详情新增该实体已上架专属商品陈列，并可直接进入同团队商城查看和购买。

- 新增独立的 `doc.lostsky.work` 用户指南站，与完整的 `docs.lostsky.work` 文档站复用 `docs/manual/` 正文，并按用户任务提供精简导航；补充双站 Linux 与 Windows 宝塔/Nginx 部署基线。

- 对象字段表单统一访问规则与布尔设置的表面、圆角和留白，移除嵌套卡片造成的视觉层级冲突。
- 团队工作台侧边栏采用深色细滚动条，并在下方仍有入口时显示可点击的发光下箭头提示。

- 删除trade应用的计划
- 实体引用胶囊和展开卡片按团队、成员、客户、虚拟实体显示可区分的语义色，未知或不可用对象保持中性灰。

### 修复

- 修复本地 Vite 代理误用生产 HTTPS 地址时，证书或静态站点兜底响应被浏览器表现为 CORS 的问题，并扩充 CORS 静态检查。
- 修复文件空状态图标偏到内容区左侧、文档列表乱码与检索能力不足，以及 Markdown 编辑器重复出现本地上传按钮、禁用图片按钮仍会插入待上传节点或在刷新后干扰正文焦点且不提示原因的问题。
- 修复 PHP 上传临时目录异常污染 JSON 时前端无反馈的问题：部署基线要求可写临时目录并关闭生产错误直出，上传界面同时增加可见错误区域。
