- [ ] 修改页面结构前已按[页面组件化方法](componentization.md)盘点已有组件、抽象候选、页面布局责任和具名例外。
- [ ] 已按[封闭组件契约](componentization.md#closed-component-contract)确认唯一视觉所有者；调用方没有穿透 `.ls-*` 私有节点、视觉参数或样式透传，新增参数满足真实变体准入条件。
- [ ] 已按页面硬性分组规范列出“组名 → 用户目标 → 包含项 → 拆分理由”；普通单个布尔项未独占面板，同目标、同权限、同生命周期的设置已合并。

## 实现

- [ ] 应用根部统一 Naive UI 2.44.1、zhCN、LostSky 主题和 Lucide 1.8 描边，页面无主题 Provider。
- [ ] 页面使用公共标题、工具栏、主体、动作、上传和异步状态组件。
- [ ] 达到抽象阈值的同义结构已全部迁移，旧类名、旧 DOM 与重复 CSS 已删除；未达到阈值的简单布局没有被提前包装。
- [ ] 涉及内部布局时源码守卫禁止父级穿透；涉及等宽、满宽、容器或溢出时 Playwright 已覆盖桌面、移动端与适用的加载、禁用或长文案状态。
- [ ] 用户截图与实时页面中发现的视觉问题已转译为实际控件之间的关系断言；组件预览只供人类验收，未被当作 Agent 输入或像素测试基线。
- [ ] 集合页有搜索、必要筛选、结果数量、连续边界和统一分页。
- [ ] 桌面动作图标+文字；移动端一个主操作+更多；同组同高度且宽度由语义组件管理，每区域最多一个主操作。
- [ ] 一个业务分组只有一个保存动作；同目标、同权限、同生命周期字段由单个接口原子提交，不以接口或数据表拆组。
- [ ] 无修改时保存不可用；远端刷新不覆盖脏草稿，提交期间的新输入不被旧回包清除，离开时统一保护未保存修改。
- [ ] 数字输入模型覆盖清空后的 `null`、非有限值、取值范围与金额平衡；提交前统一归一化，未对可空模型直接调用 `toFixed()`。
- [ ] 写入结果会成为后续表单候选时，成功流程等待对应候选缓存失效并完成刷新；主查询或候选查询失败显示可恢复错误，不退化为空白或伪装成空集合。
- [ ] `NSwitch` 等第三方底层控件只存在于其唯一公共原语内，业务页面不存在历史例外白名单；可编辑、只读和固定状态保持同一组件拓扑。
- [ ] 缺权限/能力不发请求、不在加载时误报；4xx 不重试；真实错误不清空壳层。

## 可执行静态守卫

- `npm test` 必须扫描五个后台应用和 `@lostsky/ui`：除根 `App.vue` 外不得出现 `NConfigProvider`；除[公共组件中登记的实现级例外](components.md)外不得出现原生标准控件。
- `npm test` 必须断言后台源码不导入 PrimeVue、shadcn-vue，也不出现可见“刷新”“重试”“重新检查”按钮；令牌刷新、重新登录等具名业务动作不在此禁令内。
- `npm test` 必须断言本板块八个页面都存在、导航可达，并检查公共组件新增参数已登记；不能用仅通过构建代替 Wiki 完整性检查。
- `npm run typecheck` 验证共享组件事件和 Naive UI 参数；`npm run build` 是完整静态发布构建，生成的 `www/` 只验证入口和资源完整性，不纳入 Git。
- Playwright 在 320、375、768、1024、1440px 检查 `document.documentElement.scrollWidth <= clientWidth`，并验证桌面动作带文字、移动端为“主操作 + 更多/操作”、触控区不少于 44px、权限禁用不发请求。
