# 后台设计规范

本板块是 LostSky 后台界面的唯一设计规范正文来源，适用于 `account`、`team`、`chat`、`transaction`、`admin` 以及后续后台应用。`site`、`display`、`shop` 属于前台展示界面，不套用后台壳层，但共享基础无障碍要求。

## 强制维护规则

任何未来仍需遵守、复用、解释或验收的前端规范，都必须在实现前或同一变更中写入 Wiki；无论规则跨应用、只属于一个应用、只属于一个页面，均不得以代码默认值、组件实现、设计稿、测试或口头约定代替 Wiki。单页面规则登记在[应用与页面](applications.md)，公共正文只保留一处，其他文档通过链接引用。

每条新增或变更的规范必须写明：适用范围；必须与禁止行为；组件、参数或令牌；桌面、移动端与无障碍表现；加载、空、错误、禁用及权限边界；允许例外及理由；可执行检查方法。缺少任一项即不算完整规范。

新增规则时使用以下条目模板；若某项不适用，仍须写明“不适用”及原因：

1. **范围**：应用、路由、组件和用户任务。
2. **行为**：必须做什么、禁止做什么。
3. **实现**：唯一允许的组件、props、插槽和令牌。
4. **适配**：桌面、移动端、键盘、焦点、读屏、文本放大与减少动态效果。
5. **状态**：加载、空、错误、禁用、权限、能力和恢复方式。
6. **例外**：具名例外、必要理由、影响范围和失效条件；没有例外时写“无”。
7. **验收**：可重复执行的组件、端到端、静态或人工检查。

## 优先级与术语

规范冲突时按“用户安全与权限边界 → 本板块公共规范 → 应用专属规则 → 页面登记例外”处理。例外必须具名、说明原因并给出测试方法，不允许以页面 CSS 临时覆盖形成隐含例外。

- 后台：认证后完成管理、协作或治理任务的界面。
- 主体：团队、成员、客户、虚拟实体等可被引用和操作的 Entity。
- 集合页：展示可定位对象列表并提供搜索、筛选、数量和分页的页面。
- 主操作：当前页面或区域最重要、最能推进任务的一个操作。
