# 响应式与无障碍

## 断点与布局

最低支持宽度 320px。公共行为断点使用 640、768、900/960px；应用只能在[应用与页面](applications.md)登记后增加断点。移动端优先单列，工具栏纵向，列表操作使用“主操作 + 更多”；不得依赖 hover 或桌面宽度完成核心任务。

## 触控、键盘和屏幕阅读器

- 所有交互目标至少 44×44px；图标可小于 44px，但命中区不得缩小。
- 焦点顺序必须与视觉顺序一致，`:focus-visible` 清晰可见；弹层打开后焦点进入弹层，关闭后回到触发器。
- 纯图标必须有可读名称；装饰图标 `aria-hidden`。数量变化使用礼貌播报，错误区域使用 `role=alert` 且只出现一次。
- 文本放大至 200% 时不得截断核心操作、状态或字段标签；长名称和 slug 允许换行或省略，但完整值须可访问。

## 减少动态与内容稳定

`prefers-reduced-motion` 下取消位移、循环和自动滚动；加载内容不得依赖动画结束才可见。hover、focus、loading、disabled 不得改变控件外框尺寸，避免布局抖动。

## 检查

在 320、375、768、1024、1440px 和 200% 文本缩放下检查无横向溢出；仅键盘完成搜索、筛选、打开更多菜单、进入详情、提交和取消；启用减少动态后检查无位移；使用无障碍树确认名称、角色、禁用和展开状态。
