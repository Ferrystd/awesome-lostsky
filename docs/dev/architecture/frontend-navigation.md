# 前端路由与页面间导航

本页规定后台页面归属、返回行为与 URL query 契约，适用于新增或调整的导航流程，不表示存量页面已全部迁移。页面布局见[后台页面模式](../design/admin/patterns.md)，草稿生命周期以[保存边界与草稿保护](../design/admin/componentization.md#draft-boundary)为唯一正文，权限表现见[状态与访问](../design/admin/states-and-access.md)。

## 页面归属与独立任务

- 按用户目标组织入口。辅助主任务的管理功能可归入其子页面；功能归并不等于将独立任务塞入同一表单，也不改变各自的保存与权限边界。
- 父级入口承载稳定业务分区，子任务由分区内入口进入；子页面保持所属父级导航选中，不因新增、编辑等任务重复增加顶层入口。
- 查看、新增、编辑和审核保持可刷新、可直接访问的独立路由。URL 层级表达业务归属，不强制使用嵌套视图或共享父级表单。
- 标题表达当前任务，返回入口明确目的地。直接访问、刷新或缺少可信来源时，返回声明的父页面；不得只调用浏览器后退而假设上一页属于当前流程。
- 从列表进入任务后返回，应恢复搜索、筛选、分页和浏览位置；来源状态与表单草稿分别保存。原记录删除或不再可见时回到有效列表位置，不恢复受限内容。
- 路由入口保持开放，读取和提交按现有 Permission / Ability 规则处理。URL 层级、来源和 query 均不提供授权，受限数据不得借参数泄露。
- 调整尚未完成的路由结构时同步更新全部入口，不默认保留旧路径别名或重定向；有明确兼容需求时才单独约定期限与验收。

## URL query 契约

接收 query 的页面必须在对应应用文档声明参数名、用途、类型、允许值或长度、默认值、非法值处理及冲突规则。不得把整个 query 对象直接合并进表单或 API 请求。

| 用途 | 应用规则 |
| --- | --- |
| 列表状态，如搜索、筛选、分页 | 可与 URL 持续同步；前进、后退恢复对应状态 |
| 表单预填，如操作类型、目标对象 | 仅初始化新任务；同组件内改变目标也视为任务切换，先执行草稿保护 |
| 返回上下文 | 仅接受声明的站内目标或受信来源；无效、越界或缺失时回退到稳定父页面 |

- 明确处理缺失、空字符串、重复参数和非法格式。单值参数不得通过取数组第一项或隐式转换静默接受重复值；集合参数须明确声明。未知参数不进入业务模型。
- 数字校验有限值、整数和业务范围，枚举只接受允许值，文本限制长度。无效可选预填采用声明默认值；必需目标缺失或无效时说明原因并阻止对应提交，不得自动换成其他对象。
- 外部资源链接按业务声明校验协议、域名和路径类型。返回地址与资源链接分开校验，禁止任意外部返回地址或可执行协议。
- 路径中的资源标识确定既有对象身份，query 不得覆盖同名路径标识。多个候选目标同时出现时按契约拒绝或确定唯一优先级，不由字段赋值顺序决定。
- 同一任务已有恢复草稿时，不用 query 或刷新结果覆盖；编辑既有对象时，服务端数据建立基线，query 不覆盖已有字段。明确放弃草稿或确认切换任务后才重新初始化。
- query 仅预填或定位，不自动保存、发送、点赞或执行其他写操作。资源可见性与账号使用权限仍由服务端校验。
- URL 不承载评论草稿、凭据或受限正文；需要目标信息时传允许当前用户获得的标识，再按权限读取。不得把任意表单序列化到地址栏。

## 通用能力边界与验收

页面声明业务参数和任务身份；共享工具负责基础解析、返回目标校验及导航保护。复用既有工具，按真实需求提取轻量能力，不引入自动合并页面或任意 query 驱动表单的框架。草稿机制的复用要求见[草稿规范](../design/admin/componentization.md#draft-boundary)。

改变流程时，直接相关测试至少覆盖：直接进入子页与返回兜底、父级导航归属、列表返回状态、前进后退、合法及非法和重复 query、同页切换目标、取消离开后地址与草稿不变、无权限不能借参数读取或提交。辅助子任务另验收草稿往返恢复；异步读取须验证旧目标回包不覆盖新任务。文档验收不替代后续实现测试。
