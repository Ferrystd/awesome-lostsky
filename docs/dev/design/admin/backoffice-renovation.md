# 非 Team 后台翻新

## 范围与交付

范围为 Transaction、Admin、Weibo 和 Shop `/manage`。Account、Chat、Team 保持基线不变；Community 未发布功能不恢复；Site、Display 与 Shop 前台不迁移。机器清单位于 `frontend/backoffice-preview-manifest.json`，逐路由及影响结构的变体登记模板、复用来源、预览路径和完成状态。重定向具名登记，不冒充可见页面。

全部真实页面必须有代码渲染的桌面与手机预览，索引按应用、路由与变体组织；只提供代表页或组件名不算全覆盖。模拟数据明确标记，未模拟 API 请求必须失败，不以登录跳转、错误页或 HTTP 200 代替成功预览。预览、临时服务与完整静态构建只在任务工作树，不安装到主工作区 `www`，不改常驻站点或生产。

## 模板契约

| 内容任务 | 模板 | 结构与边界 |
| --- | --- | --- |
| 多个稳定分类 | `LsCategoryPage` | 分类导航、主内容独立保存；手机选择器；不得跨应用导入 Team 组件 |
| 定位人员、角色、商品等对象 | `LsObjectDirectory` | 1024px 连续目录，轻搜索与行内动作，禁止逐条大圆角卡 |
| 账户、业务对象及事件档案 | `LsDetailPage` | 主内容与有实际价值的对象上下文；没有上下文不制造空侧栏 |
| 新建、编辑与提交任务 | `LsFormPage` | 居中专注编辑；真实摘要或预览使用已批准辅助区；保存留在主任务 |
| 工作入口及真实业务摘要 | `LsOverviewPage` | 按优先任务组织，不填充虚假指标或卡片墙 |
| 简单独立任务 | `LsSinglePanelPage` | 左对齐有阅读上限单面板，右侧可自然留白 |
| 流水、日志等多列比较 | `LsCollectionPage` | 保留搜索、筛选、批量与记录语义，不强行压为对象目录；移动记录保留字段名 |

账号身份流程与聊天应用不在本次范围，不启用此次新增场景。运行态、错误、空数据、禁用原因及权限边界沿用现有行为，不新增后端接口。

## 共用所有权

公共 UI 负责固定列宽、面板材质、控件状态和响应式；页面仅负责业务编排与插槽内容。场景由 `LsWorkspaceScene` 与 `workspaceSceneProviderProps` 显式启用，新增材质限定 `.ls-theme-aurora`，未启用的商城前台保持原默认。Team 私有 UI 不替换、不迁移。禁止通过视觉 props、任意样式透传或父级穿透修补布局。

共享 UI/外壳/覆盖清单由框架任务统一维护；业务组各自只改所属应用视图及应用组件。旧分支只读取已批准布局，不覆盖当前权限/API/草稿逻辑，也不带入 Community 依赖。`form-context-sidebars` 未提交的 TransactionForm 金额平衡提示修正须单独对照保留，不改原现场。

## 验收

直接契约与类型检查按改动范围执行；完整静态构建集中一次。各路由和变体一轮桌面/手机真实渲染，收集脚本错误、未模拟请求、横向溢出、主体宽度及操作可达性，问题集中修复后最多一次复核。预览 PNG 只供人类查看，不作为 Agent 图像输入；所有路径生成成功后才更新清单状态。键盘焦点、200% 文字、长文案与减少动态在共享模板代表场景检查，避免重复全应用业务回归。
