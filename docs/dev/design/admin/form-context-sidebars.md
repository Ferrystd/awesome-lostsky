# 表单右侧辅助区

## 范围与状态

适用于后台独立填写、对象管理与审核任务。桌面采用左主区、右辅助区；分类工作区、对象目录、总览和前台不因本规范自动改变。当前首批为成员新增/管理、对象字段新增/编辑、流水登记/编辑，等待人工批阅后再推广。顾客档案旧批阅稿仍在独立分支，未混入本次修改。

## 组件契约

沿用 `LsFormPage`，新增 `aside` 内容插槽和 `asideLabel` 可访问名称（默认“辅助信息”）。三个现有代表页分别提供成员摘要、字段预览和金额汇总，构成真实复用场景。插槽缺省时保持原单列 DOM 与外观；有右栏时标题仍跨整页，默认插槽和 footer 同处主栏，aside 在其后。不能向组件传宽度、比例、颜色或 sticky 等视觉参数。

组件唯一持有 24px 列距、2:1 比例、48rem 容器断点和窄屏堆叠。调用路由使用 content 64rem；不得仅放宽表单控件，也不得穿透共享控件。右栏复用 LsPanel / LsSectionHeader / LsDescriptionList 和实际业务组件；不嵌套相同面板，不新增主题或极光实现。为避免长右栏在矮视口不可访问，首批不吸顶、不建立独立滚动区。

## 内容与行为

- 主区保持填写、校验和原有保存动作；新增右栏不改变保存载荷、权限或草稿保护。
- 右栏优先展示既有对象信息、草稿摘要或字段预览，不新增接口、不编造统计。已保存状态与未提交草稿明确标注。
- 成员管理的对象字段、角色、搜索设置与成员状态原本具有独立保存边界，必须保留；新增成员仅凭入队码尚未取得身份，右栏不得推断或泄露该成员资料。
- 字段预览只提供本地试填，不进入业务表单、保存载荷或离开保护；显示控件应跟随现有对象字段渲染语义。
- 金额摘要只读消费表单数据；金额未填、加载、请求失败或读取受限时不得伪装成有效零值。摘要不能替代字段旁校验。
- 缺少数据、读取错误与权限受限时保留右栏容器，显示对应说明；不显示缓存中已失去读取权限的数据。

## 适配与检查

DOM 与键盘顺序为页头、主区（含保存）、右栏；关键提示留在字段附近。内容宽度不足 48rem 时右栏堆叠到主区后；无固定高度、横向裁剪或额外动效，沿用已有焦点与减少动态规则。

后续验收应覆盖三类页面及未接入旧单列页面、桌面/窄屏、长内容、200% 字号、加载/失败/受限、草稿摘要更新与原保存载荷。当前用户要求节省 token，未运行测试、typecheck 或全量构建；仅启动真实代码渲染供人工批阅，不能宣称生产验收通过。
