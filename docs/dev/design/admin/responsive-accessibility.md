# 响应式与无障碍

## 断点与布局

最低支持宽度 320px。公共行为断点使用 640、768、900/960px；应用只能在[应用与页面](applications.md)登记后增加断点。移动端优先单列，工具栏纵向，列表操作使用“主操作 + 更多”；不得依赖 hover 或桌面宽度完成核心任务。

## 触控、键盘和屏幕阅读器

- 所有交互目标至少 44×44px；图标可小于 44px，但命中区不得缩小。
- 焦点顺序必须与视觉顺序一致，`:focus-visible` 清晰可见；弹层打开后焦点进入弹层，关闭后回到触发器。
- 纯图标必须有可读名称；装饰图标 `aria-hidden`。数量变化使用礼貌播报，错误区域使用 `role=alert` 且只出现一次。
- 文本放大至 200% 时不得截断核心操作、状态或字段标签；长名称和 slug 允许换行或省略，但完整值须可访问。

## 减少动态与内容稳定

`prefers-reduced-motion` 下取消位移、循环和自动滚动；加载内容不得依赖动画结束才可见。hover、focus、loading、disabled 不得改变控件外框尺寸，避免布局抖动。

### 跨路由顶栏位置稳定

1. **范围**：所有引入 `@lostsky/ui/styles.css` 的后台应用及其共享顶栏；公开展示页、嵌入式预览和独立滚动容器不适用。
2. **行为**：内容长短导致页面垂直滚动条出现或消失时，工作区宽度和顶栏左右内容必须保持同一位置；禁止由各页面补偿边距、动态测量滚动条或覆盖顶栏内边距。
3. **实现**：共享根样式唯一使用 `html { overflow-y: scroll; }`，让所有页面始终使用真实纵向滚动条，不使用会在无滚动内容时留下可见空白的 `scrollbar-gutter`；Team、Shop、Transaction、Weibo 必须启用 `LsWorkspaceHeader` 的 `app-navigation`，由共享顶栏统一六个 5.5rem 等宽入口、0.5rem 间距、`--ink` 黑色、字号和字重，各应用不得覆盖其几何或文字样式。
4. **适配**：桌面传统滚动条浏览器始终显示滚动条；使用覆盖式滚动条的环境按浏览器原生方式显示，不额外预留空白槽位。键盘、焦点、读屏、文本放大和减少动态行为不受影响。
5. **状态**：加载、空、错误、权限禁用以及长表单都不得改变顶栏横向位置；浏览器按原生滚动行为降级，不增加脚本补偿。
6. **例外**：具有自身固定尺寸和内部滚动区的 Chat 消息时间线继续使用组件级 `scrollbar-gutter`，不替代页面根槽位；除此之外无例外。
7. **验收**：Vitest 锁定共享根样式、四个工作台的共享导航开关且禁止根节点使用 `scrollbar-gutter`；Playwright 在同一桌面视口依次打开短概览与长资料页，并在工作台中断言导航总宽 35.5rem（568px）、六个单项各宽 5.5rem（88px）、间距 0.5rem（8px）、右内边距 1.5rem（24px）以及统一文字样式。

移动端应用切换统一复用 [LsAppSwitcher](components.md#应用切换面板)，共享顶栏与 Chat 使用同一图标、两列面板、当前状态及键盘行为。通用业务命令菜单仍使用“操作”语义。

## 检查

在 320、375、768、1024、1440px 和 200% 文本缩放下检查无横向溢出；仅键盘完成搜索、筛选、打开更多菜单、进入详情、提交和取消；启用减少动态后检查无位移；使用无障碍树确认名称、角色、禁用和展开状态。
