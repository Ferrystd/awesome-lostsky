# Team 页面版型

## 分类导航项

Team 私有 `LsCategoryNavigationItem` 统一分类命令与路由入口，仅接收 `label/to/current/dirty/panelId` 语义值，发出 `select/keydown`。命令基于 Naive `NButton`，链接基于 `RouterLink`，不嵌套交互元素；组件独占既有 44px 最小目标、12px 内衬、14px 字号、选择态、焦点轮廓和未保存提示。父级仅负责集合、方向键/Home/End 与手机选择器，不穿透子项样式；既有 48rem 容器断点、路由与草稿保护不变。

本规范只约束 Team。沿用已批阅的极光、透光面板和轻量入口，不改变其他应用的公共 UI 默认行为。Team 的 `@lostsky/ui` 由 `frontend/vite.team.ts` 指向应用内适配目录。

分类工作区统一组合页面的 `LsPageHeader`、`TeamCategoryLayout` 和 `TeamCategoryNavigation`；不再保留第二套 `LsCategoryPage`。页面负责标题、动作、业务数据和草稿，布局组件负责列宽、内衬与 48rem 容器断点，导航组件负责方向键/Home/End、路由跳转和手机选择器。手机选择器必须给实际可聚焦触发器提供名称、展开状态、受控列表和活动选项，脏分类在桌面与手机都提示“未保存”；切换分类不提交或丢弃草稿。

Team 列表工具栏固定使用无底板、无外框的轻搜索结构，不再接受 `embedded` 视觉开关。所有列表使用独立业务页面；已被全部过滤的通用资源路由与 `ResourceView` 一并移除。其他应用的公共工具栏仍保留其既有面板样式。

极光为自动环境背景，不提供播放或暂停命令；同时删除只服务手动控制的注入状态。渲染器继续尊重减少动态偏好，在标签页隐藏、背景不可见或 WebGL 上下文失效时停止，在卸载时释放观察器与 GPU 资源。

## 容量与任务归属

| 版型 | Team 使用范围 | 容量和结构 |
| --- | --- | --- |
| 分类工作区 | 设置、通知、个人收件箱、审计、加入与离队审核、角色权限 | 1024px 居中；分类列 184px、列距 24px；主体桌面内衬 20px、手机 12px；手机用分类选择器 |
| 对象目录 | 文件、群聊、虚拟人员、对象字段、人员、角色、申请字段、成员、顾客、文档 | 一般目录使用 `LsObjectDirectory` 自限 1024px；文件与群聊采用下述资源工作区；页头轻入口、无外层底板的搜索筛选、连续列表 |
| 对象档案 | 人员、成员、顾客、通知详情、审计事件、审核详情、团队能力、个人权限 | `LsDetailPage`；正文与必要的只读对象上下文分别组织，保留独立保存边界 |
| 专注编辑 | 独立创建/编辑、个人资料与个人对象字段 | `LsFormPage`；无辅助区时单列上限 42rem；有真实对象摘要、草稿预览或业务上下文时采用下述已批准辅助区契约 |
| 总览 | 团队概览、个人概览 | `LsOverviewPage` 自限 1280px，以工作入口及真实摘要组织 |
| 左对齐单面板 | 供没有分类或上下文需求的独立任务使用 | 此轮既有成稿未指定 Team 页面；不为了凑齐六种强改已批准页面 |

`/doc` 是 72ch 内容阅读页，`/join` 是公开申请身份流程，属于合理专用版型。旧地址重定向不单独构成页面。

## 编辑辅助区

沿用 `codex/form-context-sidebars` 已批阅契约：`LsFormPage` 的 `aside` 存在时，路由容量为 `content` 64rem，主区与辅助区为 2:1、列距 24px；容器不足 48rem 时按主区、辅助区顺序堆叠。标题跨整页，保存保持在主任务内。没有 `aside` 的编辑页使用居中 42rem 容量。不得机械删除已经批准的成员摘要、字段预览、文档属性等业务上下文。

个人资料、个人字段是编辑任务，使用表单版型，继续保留已保存身份侧栏及原草稿/保存逻辑；个人角色与权限是只读档案，继续使用详情版型。

## 交付检查

Team 页面检查同时核对源路由、Vite 实际解析组件、静态 HTTP 入口与 lazy chunk，以及浏览器 DOM。组件名存在不能单独证明版型完成。`frontend/scripts/team-template-audit.mjs` 在真实本机静态站点上使用明确模拟业务数据记录全部页面的桌面/手机结构、宽度、溢出、旧工具栏与脚本错误；其模拟结果不代表真实账号权限或业务写入验收。组件预览只供人类查看。

## 文件与群聊资源工作区

`TeamResourceWorkspace` 仅服务 Team 的 `/files` 与 `/chat-groups`。使用现有极光、透光材质与字号；1024px 内容上限，页头跨列，正文为 `minmax(0, 2fr) minmax(15rem, 1fr)`，列距 24px。容器不足 48rem 时堆叠。组件固定负责列宽、间距、响应式，页面不传视觉参数。

- `actions` 为页头真实入口；`toolbar` 为轻搜索；默认插槽是主列表；`pagination` 留在主区末尾。
- `filters` 表示影响整个集合的范围控制，桌面在右列，小屏必须在搜索和列表之前。
- `context` 表示当前资源的资料，桌面在右列，小屏在列表之后。两页各使用一个辅助插槽，不增加万能布局参数。
- 文件：主区负责查找、选择、打开和删除；右栏呈现所选文件名称、来源业务、来源人员、上传时间与真实存储容量。来源未记录时如实显示，不用未知字段挤压列表。分页、搜索、删除或权限变化导致选择不可见时，选择回到当前可见首项；没有数据时清空。每项标题是到资料区的真实锚点，打开文件仍为独立链接，删除仍在更多菜单中确认。
- 群聊：主区负责进入群聊管理；右栏使用实际 `is_closed` 计算全部、进行中、已关闭范围，控制本地过滤。计数基于当前完整查询，不用参与者累计数冒充人数统计；失败、加载、受限时不显示伪零计数。保留创建入口与详情权限。
- `TeamResourceEntry` 为这两页连续资源项的唯一视觉所有者：20px 无底板图标，名称与状态为首层，简短真实属性为次层，操作独立放在尾部；只有分隔线，无每项圆角卡。所选文件以浅透光面和可访问的当前项状态标示，不靠颜色单独表达。
- 单条、空数据和多条记录均保持相同两区结构，不添加空白占位行或假指标。辅助区由 `LsPanel` 提供现有透光面，不新增外层大卡片。

Team 私有 `LsButton` 的 `danger` 沿用 `secondary` 的虚线内边界与暗色命令底，前景使用危险色；`danger-ghost` 保留无底行内操作。仅修正视觉所有者，不改变确认、加载、禁用原因和执行语义，其他应用的公共按钮不变。

## 移动操作与搜索

Team 页头动作由 `LsPageHeader` 统一持有，`LsDetailPage` 将动作插槽交给它并保留原返回导航顺序。手机上标题位于左上、双链接紧凑并排在右上，说明跨列在下方自然展开；长文案与 200% 文字可自然换行，不能与操作区重叠或截断，保留图标、完整名称及至少 44px 触控区。行内对话/管理继续由 `LsResourceRow` 与 `LsPageLink` 组织，无新增视觉参数或页面穿透。

`LsFormActions` 在手机上将两个普通命令等分为两列，只有一个命令时占满行；`LsButton` 自己持有可换行标签、自然高度和最小 44px 触控区，不能由表单穿透内容盒修补长文案。

`LsListToolbar` 的搜索、筛选、动作与结果数量始终在同一横向轨道；搜索允许收缩，单个筛选自适应，多个筛选在自身区域横向滚动且全部可聚焦操作，不撑宽页面。结果数量保留并可在自身区域换行。加载、空、错误与权限处理继续由业务内容负责，禁用/加载动作沿用现有组件行为。

集合、分类、详情、表单、概览和专用页面不再提供极光暂停/播放入口；极光渲染继续遵守系统减少动态效果、页面不可见和离屏暂停。无新增例外。以 `tests/mobile-template-layout.spec.ts` 核对 320、375、390、768、1440px、长文案、200% 文本、双动作及单行搜索的真实 DOM 关系。

极光页面的 HTML 入口直接声明关键画布底色 `#101619`、`color-scheme: dark` 和匹配的浏览器主题色，不能等待 Vue 或外部样式加载才变深色。首次挂载等待路由就绪，避免未确定场景时先绘制浅色 Provider；Team 的公开 `/join` 同样属于极光入口。用 `tests/team-first-paint.spec.ts` 分别延迟主脚本与路由访问快照，核对 HTML、CSS 到达和首次挂载三个阶段的真实背景。
