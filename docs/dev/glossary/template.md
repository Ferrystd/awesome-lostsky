# 专有名词单页模板

本页定义开发术语单页的统一结构。新增开发术语时复制下方 Markdown 模板，再更新登记表、索引和导航；任何 Markdown 编辑器均可使用，不依赖仓库外模板。

## 页面约定

- 文件名：英文小写连字符 slug，例如 `virtual.md`。
- frontmatter：`title`（双语）、`description`（一句话）、`tags: [glossary]`、`status`（`待编写` / `已建页` / `生成文档`）、`aliases`（中文名与英文名）。
- H1 与 `title` 一致，双语 `# 中文名（English）`。

## 小节结构

```markdown
---
title: 中文名（English）
description: 一句话说明，待补充。
tags: [glossary]
status: 待编写
aliases: [中文名, English]
---

# 中文名（English）

## 定义

待补充。

## 使用场景

待补充。

## 不包括什么

- 待补充。

## 相关概念

- 待补充。

## 来源与示例

待补充。
```

各小节约定：

- **定义**：一句话给出概念边界，不写实现细节。
- **使用场景**：说明该概念何时、如何被消费。
- **不包括什么**：1–3 条反例，排除常见误读。
- **相关概念**：使用相对路径链接列出相关术语，并保持无序列表格式；新增页面时替换为实际文件名。
- **来源与示例**：开发侧（`docs/dev/glossary/`）指向代码或架构文档并给实现示例。开发术语由 AI 维护；用户侧术语由人工维护，本模板不创建或改写用户侧页面，需要用户解释时仅反馈建议。

## 特殊类

- **生成文档**（如 [service.md](service.md)）：由命令生成，结构豁免；frontmatter 由生成器负责，`status` 固定为 `生成文档`，禁止手改。
- **词簇页**：一页解释一组相关子概念时可豁免小节结构，但必须保留 frontmatter 与双语 H1，并在登记表中说明词簇边界；本模板不提供现成词簇页示例。

页面命名使用稳定的小写连字符文件名；中文、英文和页面文件名确定后，不因界面文案的小改动频繁更名。
