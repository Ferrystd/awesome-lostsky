## 样板契约

- `LsObjectDirectory` 组合既有 `LsCollectionPage`，统一 64rem（默认 1024px）最大内容宽度、页头到正文 24px、搜索筛选到列表 16px；只接收 title/description 与 actions/toolbar/default/pagination 插槽，无视觉参数，不改变其他集合页。
- `LsListToolbar` 使用既有 `embedded` 语义：无贯穿整行的厚外卡片。搜索、归属、状态与数量顺序不变；手机搜索单独一行，筛选自然换行。
- `LsResourceList` 与 `LsResourceRow` 提供连续边界、透明场景材质、链接与响应式布局。主信息为头像、顾客名称与紧随的状态；次信息为顾客类型、slug、真实归属人及其 slug。余额和创建时间位于次要区域。长名称与标识自然换行，不截断，不固定行高。
- 主信息链接保持 `/customers/:id`；末尾箭头仅提示进入详情。不存在列表封禁命令，不新增或移动详情中的业务命令；不嵌套链接。默认链接支持键盘聚焦，名称与“查看详情”共同提供可访问名称，头像与箭头为装饰。
- 成员与顾客的两行身份内容达到复用阈值，由 `LsDirectoryIdentity` 统一承载；原顾客私有身份 CSS 已删除。它保留真实头像、类型、名称、slug 与状态，允许长文本换行，不改变其他页面使用的 `LsEntityIdentity`。
- `LsDirectoryActions` 为成员和文档提供各尺寸一致的更多命令菜单，原禁用项及其解释保留；主导航与管理/编辑链接仍独立存在。封禁、解封、离职和删除仍走原确认与请求。
- 列表加载、真实失败、空结果及读取受限继续通过 `LsAsyncState`、`LsEmptyState` 在正文呈现，页头与工具区不撤换。原接口、权限、身份范围、归属候选、筛选重置和分页参数不变。
- 本试点取代本页的旧响应式表格结构及其列渲染器；不改其他表格、黄金页、路由 meta、极光或主题。`patterns.md` 中原 Team 顾客表格要求在本试点由本条替代，仅推广到上述对象目录，其他集合页不受影响。
