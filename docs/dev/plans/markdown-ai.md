# Markdown 编辑器 AI 能力计划

> 状态：未实现。当前版本不提供 AI 入口。

当前版本只提供本地可视化编辑、预览、图片上传和 `@对象` 引用，不展示 AI 入口，也不在浏览器保存任何模型密钥。以后启用 AI 时需要同时完成：

- 后端代理：所有模型请求由服务端发起，顾客端不得持有供应商密钥。
- 流式输出：使用可取消的流式协议，并处理断线续传、超时和重试。
- 差异确认：AI 修改先展示可审阅差异，由用户明确接受后再写入编辑器。
- 权限：复用文档和成员资料的查看、编辑权限，禁止 AI 越权读取引用对象。
- 额度：按用户、团队和应用设置调用额度、并发限制与成本上限。
- 审计：记录操作者、来源字段、模型、用量和接受结果，但不记录密钥。
- 隐私：明确数据保留策略、第三方处理边界、敏感信息过滤和用户告知。
- 安全：防提示词注入，工具调用采用白名单，并对模型输出继续执行 XSS 清洗。

完成以上基础设施后，再启用 Milkdown 的 AI 功能并设计独立的生成、改写和摘要交互。

## 启用验收

- 未授权、额度耗尽与模型故障分别返回可解释结果，不改写现有草稿。
- 取消、断线和重复提交不会重复扣费或覆盖用户继续输入的内容；接受差异前可完整放弃生成结果。
- 引用对象按操作者权限逐项校验，模型输出仍经过现有 Markdown 清洗；浏览器资源、请求与日志中没有供应商密钥。
- 同时覆盖成功生成、拒绝、取消、超时和费用核对，再更新开发正文并交由人工补充使用手册。供应商、预算及数据保留期限须在实现前确认，本计划不预设已接入任何模型。
