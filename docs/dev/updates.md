# 最近更新

本页只保留最近两个正式产品版本的摘要；未发布变更、预发布进展与更早版本见[变更日志](changelog.md)。

## v1.0.2（2026-10-18）

### 变更

- Team 工作台统一极光背景与分类、目录、详情、编辑版型；其他应用不迁移新版视觉。
- 账号恢复支持验证绑定手机号后重置密码或更换绑定手机号。
- 人员字段编辑页可分页查看已保存的人员填写值，并保留权限与空值语义。
- 顾客应用入口按身份精简，移动端应用切换与平台兑换活动入口更易访问。

### 修复

- 修复平台兑换活动与 Team 文档路由前缀匹配错误，以及 Markdown 文件引用恢复问题。
- 修复平台和平板、商城窄屏下的导航可达性；本版不包含 Community 应用。

## v1.0.0（2026-10-06）

- 官网可由后台维护备案、人员和团队优势信息，首页入口直达试用文档、服务展示与商品合集。
- Team 与 Chat 增加群聊、跨团队协作和文档分权；身份汇总及受限入口遵循当前授权范围。
- Shop 统一商品规格与订单快照；权益重试、名额并发、金额分摊及协作归属保持一致。
- Weibo 点单评论支持逐帖互动、草稿恢复和缓存错误提示；任务取消、解绑与重投边界更安全。
- 文件来源和上传隔离更清晰；表单说明禁用原因，宝塔部署采用官方流程并保护配置文件权限。

## v0.1.8（2026-08-26）

- 新增 Weibo 团队应用，覆盖账号绑定、图片准备、超话单次操作、随机间隔任务、每日签到及近 30 天执行记录；外部写请求保持单次调用且不自动重试。
- Weibo 团队概览升级为调度 Dashboard，集中呈现下一次执行、账号健康、任务状态、异常记录与连续工作入口；个人概览保持共享工作台结构。
- Weibo Ability 仅控制远端写入和任务执行，账号、媒体、任务配置与日志在能力缺失时仍可使用，并显示可恢复的禁用原因。
