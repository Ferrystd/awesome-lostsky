# 外部写操作与日志保留

外部写操作只保存足以定位结果的最小结构化数据：HTTP 状态、远程 code/message、归一化 reason、远程资源 ID、本地调度键与时间。禁止保存完整远程响应、授权头、Cookie、token、签名参数或其他凭据。无法确认的结果使用 `unknown`，不根据模糊文案猜测成功或失败。

执行流程固定为：

1. 在本地事务内以唯一 `dispatch_key` 提交 `dispatching`；
2. 事务外发出最多一次远程写请求；
3. 只回写最小结构化结果；
4. 重投发现已有 `dispatching` 时，改为 `unknown` 且不重发远程写请求。

操作日志默认保留 30 天。`system:cleanup` 必须使用有限批次硬删除超期日志；同一清理周期可删除超期且未被业务资源引用的外部媒体元数据。资源有限时不通过保存完整响应“以备万一”。
