# 专有名词单页模板

复制本页创建新术语页后，再填写各小节；本模板不是术语定义本身。

```markdown
---
title: 中文名（English）
description: 一句话说明，待人工补充。
---

# 中文名（English）

## 定义

待人工补充。

## 适用范围

待人工补充。

## 不包括什么

待人工补充。

## 相关概念

- 待人工补充。

## 来源与示例

待人工补充。
```

页面命名使用稳定的小写连字符文件名；中文、英文和页面文件名确定后，不因界面文案的小改动频繁更名。
