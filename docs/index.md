# LostSky 文档

`docs/` 是 LostSky 所有项目文档的唯一正文来源。`docs.lostsky.work` 发布完整项目文档；`doc.lostsky.work` 复用 `manual/` 内容，只发布面向用户的使用指南。

`manual/` 是人工编写的用户侧文档；其余是 AI 维护的开发侧文档。AI 可只读参考手册并反馈差异，不自动改写或双向同步。具体分工与核验流程见[文档管理与发布](development/wiki.md)。
