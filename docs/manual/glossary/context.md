# 上下文(Context)

## 定义

上下文(Context)是登录并领取身份后，系统为当前请求记录的可信业务身份信息。它说明“这次操作由哪个团队、哪个成员或顾客发起”。

## 使用场景

订单、聊天、流水等业务会依据上下文按当前实体计算，而不是凭登录账号去猜测身份。没有实体身份时，系统也不会从账号关系推断成员或顾客。

## 不包括什么

- 不把登录账号自动当作业务主体。
- 不负责权限判断，只提供可信身份信息。
- 没有实体身份时，不推断成员或顾客身份。

## 相关概念

- [实体(Entity)](entity.md)是上下文的身份来源。
- [权限(Permission)](permission.md)在上下文之上做具体授权判断。

## 示例

顾客在商城下单时，系统按当前顾客实体读取其资料与余额，而不是从登录账号的关联关系去猜测顾客是谁。
