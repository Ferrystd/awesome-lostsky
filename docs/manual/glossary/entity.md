# 实体(Entity)

## 定义

实体(Entity)是团队业务中的当前执行主体。登录账号回答“你是谁”，实体回答“你以谁的身份操作”。业务操作以当前实体身份完成，审计仍可追溯到真实账号。

## 使用场景

成员、顾客、团队和虚拟实体都可以作为实体参与业务。一个实体在被授权后可以代表另一个实体操作，例如成员领取顾客身份后以顾客身份下单。

## 不包括什么

- 不替代登录账号：账号负责登录、设备和审计。
- 不是固定单一类型：成员、顾客、团队与虚拟实体各有承载方式。

## 相关概念

- [团队成员](team-member.md)与[团队顾客](team-customer.md)是常见实体类型。
- [上下文(Context)](context.md)从当前实体补充业务身份。
- [权限(Permission)](permission.md)决定实体能否执行受保护操作。

## 示例

成员领取顾客实体后，以顾客身份查看订单与余额，而系统审计仍记录真实账号与设备。
