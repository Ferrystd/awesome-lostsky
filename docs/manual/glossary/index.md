# 名词解释

本页从用户视角解释 LostSky 里常用的专有名词。理解这些名词后，再看[核心概念](../concepts.md)和具体功能章节会更容易。

## 核心主体与标识

- [实体(Entity)](entity.md)：团队业务中的当前执行主体。
- [标识(Slug)](slug.md)：实体的全局唯一、稳定且面向人阅读的标识。
- [团队成员(Team Member)](team-member.md)：与真实账号关联的团队内成员实体。
- [团队顾客(Team Customer)](team-customer.md)：团队维护的顾客实体，可关联真实用户。
- [顾客(Customer)](customer.md)：团队业务中的消费主体。
- [团队(Team)](team.md)：资料与业务所属的工作空间。
- [虚拟实体(Virtual)](virtual.md)：没有账号、可配置 Webhook 接入的自动化主体。

## 访问控制

- [权限(Permission)](permission.md)：团队角色授予的细粒度授权键。
- [能力(Ability)](ability.md)：团队是否开通某项产品能力的标识。
- [上下文(Context)](context.md)：当前身份带入请求的可信业务上下文。
- [角色(Role)](role.md)：一组职责与权限的载体。

## 系统与通信

- [通知(Notice)](notice.md)：区分「通知」与「站内通知」。
- [团队域名(Team Domain)](team-domain.md)：将自定义域名解析到团队。
