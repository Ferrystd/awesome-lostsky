# 使用手册

这里是 LostSky 面向用户的使用指南。它从任务出发，说明谁可以完成什么操作、需要哪些前置条件，以及操作成功后会看到什么结果。

## 按你的任务阅读

| 我想要…… | 阅读 |
| --- | --- |
| 注册、登录、创建或进入团队 | [账号、团队与身份](account-and-identity.md) |
| 管理团队资料、成员、权限、内容和加入申请 | [团队工作台](team-workspace.md) |
| 选择团队并发起会话 | [聊天](chat.md) |
| 记录流水、查看统计、维护客户余额 | [记账与客户余额](transactions.md) |
| 展示团队、浏览商品、维护商家客户资料或以客户身份购买 | [公开主页与商城](public-pages-and-shop.md) |
| 治理整个平台 | [平台管理](platform-admin.md) |

第一次使用时，建议先完成[账号、团队与身份](account-and-identity.md)，再进入与你职责相关的手册。

## 怎样阅读功能说明

每项功能使用稳定编号，并至少说明：

- **用户与目标**：谁要解决什么问题。
- **前置条件**：所需登录状态、当前身份、团队能力或权限。
- **操作与结果**：用户可以执行的操作及应看到的结果。
- **边界与恢复**：不支持的情况、失败提示和可继续操作的路径。

指南只陈述当前已经发布的能力，不把计划中的功能混入可执行步骤。若实际界面与指南不一致，请以界面的权限提示和可恢复操作为线索，并向团队负责人或 LostSky 管理员确认。
