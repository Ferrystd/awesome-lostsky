# 平台管理

Admin 管理 LostSky 平台本身，不代替团队管理员编辑团队内容。普通团队运营者不需要进入本手册。

## 功能基线

| 编号 | 用户目标 | 前置条件 | 应有结果 |
| --- | --- | --- | --- |
| ADMIN-01 | 查看平台概况 | 平台总览权限 | 看到平台状态和近期需关注信息 |
| ADMIN-02 | 查询或治理用户 | 对应用户读取或治理权限 | 可查看脱敏资料，并按权限封禁、解封或撤销会话 |
| ADMIN-03 | 查询或治理团队 | 对应团队读取或治理权限 | 可查看团队状态，并按权限封禁或解封 |
| ADMIN-04 | 管理平台管理员与角色 | 平台访问管理权限 | 角色和管理员绑定被保存且不破坏超级管理员安全线 |
| ADMIN-05 | 查看审计与系统状态 | 对应审计或系统权限 | 看到经授权、经脱敏的平台信息 |

## 治理用户与团队

用户和团队列表用于定位治理对象。使用完整手机或邮箱搜索及查看完整联系方式都需要额外敏感信息权限。封禁、解封用户或团队，以及撤销用户会话时，必须填写治理原因；结果会进入平台审计。

解封用户不会恢复旧会话。团队封禁和解封会立即作用于全部标准域名及自定义域名，不修改团队内容，也不影响用户在其他有效团队的会话。

## 管理平台访问

平台角色与团队角色完全隔离。管理员的有效平台权限取所绑定角色的并集。保存平台角色时，角色资料和权限作为一个整体生效；保存失败不会留下只更新一部分的结果。

系统禁止管理员修改自己的平台角色、封禁自己，或执行会导致平台没有可用超级管理员的操作。首位超级管理员由有服务器权限的运维人员通过控制台授予。

## 当前边界

平台用户、团队、管理员、角色和审计页使用统一搜索筛选栏、结果数量和连续列表/表格；没有数据或筛选无结果时，统一显示有边界的空面板、当前情况和下一步提示。平台命令搜索仍可用 Ctrl/Cmd+K 或 `/` 打开。数据在进入、窗口重新聚焦和短暂网络故障恢复后自动更新；系统状态及错误区域不提供手动“重新检查”或“重试”按钮。

已知缺少平台权限时不会发起对应受保护请求，也不会在页面加载时弹权限错误；入口按权限隐藏或稳定禁用，所有治理写操作仍由服务端再次鉴权。

- 首版不提供用户删除、密码重置、身份代办或团队内容编辑。
- 首版不提供能力授权、域名管理、订单交易治理、审计导出、队列重试或自动修复。
- 前端隐藏入口仅帮助理解权限，所有治理操作仍由服务端重新校验。
