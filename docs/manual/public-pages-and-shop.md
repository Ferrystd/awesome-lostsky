# 公开主页与商城

Display 和 Shop 是面向外部访客的团队前台。公开浏览不要求登录；购买、查看订单和取消订单需要登录并领取该商家的客户身份。

## 功能基线

| 编号 | 用户目标 | 前置条件 | 应有结果 |
| --- | --- | --- | --- |
| DISPLAY-01 | 浏览团队公开主页 | 团队有效 | 看到团队公开资料、实体目录和公开文档 |
| DISPLAY-02 | 查看公开实体 | 实体有效且已公开 | 看到公开资料、公开角色、专属商品和公开文档 |
| SHOP-01 | 浏览商品 | 团队有效且商品已上架 | 看到公开商品列表和脱敏详情 |
| SHOP-02 | 领取商家客户身份 | 已登录，来源尚未绑定该商家 | 创建或进入稳定客户身份 |
| SHOP-03 | 使用预存余额购买 | 当前商家客户身份且余额足够 | 生成订单并按服务端金额扣减余额 |
| SHOP-04 | 维护当前商家的客户资料 | 当前商家客户身份有效 | 可修改团队内昵称、头像和简介，并查看不可变 slug |
| SHOP-05 | 查看自己的订单 | 当前商家客户身份 | 只能看到当前客户的订单和详情 |
| SHOP-06 | 取消自己的订单 | 订单属于当前客户且仍可取消 | 订单标记取消，预存余额只退回一次 |
| SHOP-07 | 保留邀请来源并登记归属 | 从带 `ref` 的展示页进入并首次领取客户身份 | 邀请实体成为当前归属，后续页面与二次转发继续携带该标识 |
| SHOP-08 | 修改自己的服务归属 | 当前商家客户身份有效 | 可从同团队 Team、成员或虚拟实体中选择，也可清空 |

## 浏览公开主页

访问 `https://{team}.display.lostsky.work` 查看团队公开资料。实体只有在有效且开启公开展示时才会进入目录；客户实体不会公开。公开角色只展示名称和说明，不展示权限。实体详情同时陈列归属于该实体且已上架的商品，点击商品会进入同团队 Shop 的公开详情；团队公用、归属其他实体或已下架的商品不会出现在该实体页面。

公开文档可以从团队或实体页面进入。私有、跨团队或归属于隐藏实体的文档不会因为知道文档编号而开放。

受邀访问时，展示页使用 `?ref=<邀请实体 slug>` 保存邀请来源。只要 URL 中出现合法 `ref`，浏览器就更新本地记录；同一团队的后续展示页、商城跳转和二次转发会自动补回该参数。首次领取商家客户身份时，服务端只接受当前团队的 Team、成员或虚拟实体作为初始归属；无效、跨团队或 Customer slug 会被忽略。领取完成后再次打开其他邀请链接不会暗中改写既有归属。

## 浏览与购买

访问 `https://{team}.shop.lostsky.work` 浏览上架商品。商品公开详情不会展示成本、分成和内部接单配置。

购买时先登录并领取当前商家的客户身份。确认页面展示的商品、数量和应付金额后提交，价格、成本与分成均由服务端重新计算，不能由浏览器自行指定。

进入“我的资料”可维护当前商家团队内使用的昵称、头像、简介和服务归属。归属候选只包含当前团队有效的 Team、成员与虚拟实体，客户本人可以改选或清空；团队后台具备客户管理权限的实体也可以修改。客户不会进入公开目录，slug 只用于身份与内部引用；已有 slug 只读，只有历史缺失 slug 的客户需要首次领取。直接打开资料深链接时，商城会自动验证当前客户，不要求先从商城首页或订单页进入。当前身份尚未绑定该商家时，完成绑定后会返回资料页；身份不匹配、封禁或网络错误会显示明确状态。

购买后在“我的订单”查看进度。只有订单所属客户可以取消仍处于可取消阶段的订单；取消成功后，订单会保留取消状态，预存余额与退款日志不会重复写入。

## 当前边界

- 首版没有购物车、在线充值或第三方支付；客户使用商家预存余额直接购买。
- Display 首版只读，不提供加入申请、聊天动作、自定义域名或团队主题。
- 实体详情只展示商品名称、简介、封面和售价，不公开成本、分成或内部接单配置。
- 客户身份绑定属于当前商家且不可转移；服务归属可以由客户本人或具备后台客户管理权限的实体修改。来源身份失效、客户封禁或会话撤销后，旧客户会话不能继续使用。
- 客户昵称和简介按商家团队隔离，不作为公开资料，也不产生公开客户主页。
- 商品是否生成关联流水取决于团队设置和 Transaction 能力；这不改变客户订单与余额结果。
