# 记账与客户余额

Transaction 用于团队经营记录。所有金额、客户、处理实体和绑定关系都以当前团队为边界，页面是否可见以及能否写入由团队能力和角色权限共同决定。

## 功能基线

| 编号 | 用户目标 | 典型前置条件 | 应有结果 |
| --- | --- | --- | --- |
| TRANS-01 | 查询流水 | 流水读取权限 | 可按当前范围查看流水和详情 |
| TRANS-02 | 新建或编辑流水 | 记账能力与流水写入权限 | 合法金额和团队实体关系被保存 |
| TRANS-03 | 删除流水 | 流水删除权限 | 流水按业务规则移除，不留下错误余额 |
| TRANS-04 | 查看经营统计 | 记账能力与报表权限 | 按汇总、实体、时间或客户得到统计 |
| TRANS-05 | 维护发单绑定 | 流水写入权限 | 客户与发单实体的关系被保存或解除 |
| TRANS-06 | 查询客户余额 | 流水读取权限 | 可查看客户余额及变动明细 |
| TRANS-07 | 为客户充值 | 记账能力与流水写入权限 | 余额和余额日志在同一次操作中更新 |
| TRANS-08 | 分享客户邀请链接 | 报表权限且当前身份可作为归属实体 | 得到带当前实体 slug 的展示页链接 |
| TRANS-09 | 查看归属业绩 | 报表权限 | 按流水创建时快照的归属统计客户数、流水数与金额 |

## 流水与统计

在“流水”查看记录，进入详情后按权限编辑或删除。新建流水时只能选择当前团队的有效实体和客户；金额必须为非负有效数值。已保存流水的处理实体不能通过编辑替换。

“经营统计”用于按业务需要查看汇总、角色实体、时间、客户或归属业绩。统计权限与普通流水读取权限分开配置。归属业绩按流水创建时写入的 `sender_entity_id` 统计：客户数为所选时间范围内发生交易的去重客户数，修改客户当前归属不会追溯改写历史流水。

统计页的“复制邀请链接”会生成 `https://{team}.display.lostsky.work/?ref=<当前实体 slug>` 对应的访问地址。Team、成员和虚拟实体可以成为邀请归属，Customer 不能作为邀请人。

## 绑定、余额与充值

“发单绑定”继续维护客户与发单实体的额外协作关系。客户存在当前归属时，创建订单或流水会优先把该归属快照为发单实体；额外绑定不替代当前归属。团队管理员可以在权限范围内新增或解除绑定。

“客户余额”展示预存余额；进入单个客户可查看余额明细。充值成功时余额与日志应同时更新，失败时不应只改动其中一项。

## 当前边界

- Transaction 不是银行账户或第三方支付工具；余额是团队维护的商家预存余额。
- 当前身份必须属于地址对应的团队，且不能凭其他团队的角色访问数据。
- 页面允许选择的对象不代表最终授权，提交时仍会重新校验实体状态、权限和团队归属。
