# 卡密、订阅与资产交易计划

> 状态：未实现。本页是产品设想，不代表现行应用、路由或接口。

## 商店

计划支持套餐浏览和购买：

- 浏览可购买的商品或套餐。
- 直接下单购买套餐。
- 按面额和数量购买卡密。

## 卡密兑换

计划支持：

- 提交卡号和密钥进行核销。
- 只验证卡密有效性而不消费卡密。

## 资产

计划为用户提供统一的资产入口：

- 查看有效订阅和订阅详情，包括剩余时间与配额。
- 查看持有的未使用卡密及其面额、类型和有效期。

## 订单

计划支持购买订单列表、详情、继续支付未完成订单，以及取消待支付订单。

实现此计划前需要重新确认产品模型、支付边界、权限和接口设计，并另行补充 OpenAPI；不得将本页中的名称直接视为已确定的控制器或路由。
