# 最近更新

本页只保留最近两个版本的摘要，完整记录见[变更日志](changelog.md)。

## v0.1.2（开发中）

- 新增公开 Wiki、Display 团队主页和展示型 Shop，并补齐公开文档、实体资料与商城顾客流程。
- 将业务身份统一为 Entity，完善跨团队委托、会话证明链、细粒度权限目录和身份切换回跳。
- 强化 refresh token、请求去重、外部副作用补偿、并发锁和数据库外键等安全与一致性边界。
- 统一 Team 后台的成员、角色、资料和设置任务页，并补齐移动端、键盘与 Markdown 安全体验。
- 扩展 OpenAPI、后端集成测试、前端类型检查、构建和浏览器 E2E 验证。

## v0.1.1（2026-07-20）

- 新增 Chat 应用、虚拟实体、客户身份、实时事件与 Webhook 投递。
- 新增 Transaction 前端与后端集成测试，覆盖流水、统计、发单绑定和客户余额。
- 引入可撤销 Entity 身份 JWT、动态权限和团队后台的聊天配置能力。
- 统一多应用路由、跨子域登录回跳、OpenAPI 类型生成和前端构建流程。
