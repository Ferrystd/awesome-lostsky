# 最近更新

本页只保留最近两个版本的摘要，完整记录见[变更日志](changelog.md)。

## v0.1.8（2026-08-26）

- 新增 Weibo 团队应用，覆盖账号绑定、图片准备、超话单次操作、随机间隔任务、每日签到及近 30 天执行记录；外部写请求保持单次调用且不自动重试。
- Weibo 团队概览升级为调度 Dashboard，集中呈现下一次执行、账号健康、任务状态、异常记录与连续工作入口；个人概览保持共享工作台结构。
- Weibo Ability 仅控制远端写入和任务执行，账号、媒体、任务配置与日志在能力缺失时仍可使用，并显示可恢复的禁用原因。

## v0.1.7（2026-08-22）

- Admin 团队能力支持仅凭准确 slug 开通、调级和续期，不要求读取全量团队，并保留团队详情预填与审计记录。
- 统一 Vue 前端深链接回退与静态资源 404 边界，补齐 Transaction 接单、服务核销、权益和工作台流程。
- 完善 Account 身份切换、Team 概览入口、后台表单反馈及相关 OpenAPI、文档和测试契约。

## v0.1.5（2026-08-07）

- Team、Shop 与 Transaction 新增个人/团队工作台，六个工作台固定概览入口并支持双向切换。
- Account 实体自管迁入 Team 个人工作台，客户资料继续由商城客户中心承载。
- Shop 商家后台、Transaction 服务收款与核销、Ability 权益和公开实体目录完成联动。
- 权限域完成开发期硬切换，个人业务查询按当前 `acting_entity` 强制隔离。
