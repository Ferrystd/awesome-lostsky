## 简述

该应用给予团队内部与外部通信能力。

## 功能

- 无好友概念，可随时建立会话通信。
- 会话支持设置过期时间。
- 跨团队发起会话。

## 最佳实践

### 客服售后

会话间独立，例如关于不同售后发起独立的会话。

### 信息保密

禁用或离职成员账号后，自动无法再登录团队，自然也无法再查看**任何聊天记录**。

> 我们的设计是秉承着最大化利好团队的原则。
