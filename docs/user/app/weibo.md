## 简述

除去涵盖同行的所有机器人功能，我们加入了团队自动加入个人账号的多账号管理。

## 功能

- 超话自动签到
- 超话手动/自动发帖（不限超话）
- 指定帖子的评论点赞
- 使用下辖内部人员微博账号执行相同功能

## 最佳实践

### 舆论公关

1. 发布相关舆论贴
2. 使用成员微博账号在评论区附和
3. 舆论走向偏向该帖

### 软广宣传

1. 使用成员微博账号
2. 发软广贴，如：询问某团充卡事宜
3. 本团队热度增加
