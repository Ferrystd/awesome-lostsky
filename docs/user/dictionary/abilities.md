## 前置工作

未拥有有效能力时，一般视为**拥有 0 级能力**。
即便团队没有能力，通常也能进行资源管理，为获取能力后的业务做准备。

## 文档（`Doc`）

无有效能力时，无法对已有文档进行管理。

|  等级 | 能否使用 |
| --: | ---: |
|   0 |    否 |
|   1 |    是 |

## 文件（`File`）

团队的**一切文件**（大多是各个功能上传的图片）都会占用**额度**。

|  等级 |      额度 |
| --: | ------: |
|   0 | 128 MiB |
|   1 | 500 MiB |
|   2 |   2 GiB |
|   3 |      不限 |

额度用尽时，所有入口无法上传文件。团队需要**删除已有文件**或**升级能力**以恢复业务。

## 记账

见[记账]。

没有`记账`能力时，已有数据仍可查看，无法进行新的业务操作。

> `记账`能力过期会导致商品无法接单核销

|  等级 | 能否使用 |
| --: | ---: |
|   0 |    否 |
|   1 |    是 |

## 商城

见[商城]。

没有`商城`能力时，允许管理商品。
`开放商城`需要`商城`能力才可打开，过期时**自动关闭**。

|  等级 | 能否使用 |
| --: | ---: |
|   0 |    否 |
|   1 |    是 |

## 微博

见[微博]。

没有`微博`能力时，允许管理任务，但无法执行签到、发帖、点赞等操作。
过期时所有任务**自动关闭**，续费后需要**手动开启**。

|  等级 | 能否使用 |
| --: | ---: |
|   0 |    否 |
|   1 |    是 |
