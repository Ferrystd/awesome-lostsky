后台页面模式¶

顶栏与页面标题¶

team、transaction、admin 使用同一 LsWorkspaceHeader。桌面动作必须为图标加文字；移动端统一进入带文字的“操作”菜单。认证和会话应用可保留专属壳层，但主题、控件和主体识别必须一致。页面内容使用 LsPage 和 LsPageHeader，不得复制不同高度、字号或返回样式。

搜索、筛选与集合页¶

可定位集合页必须使用 LsListToolbar，包括 Team 的实体、成员、客户、文件、文档、角色、虚拟实体、通知、加入审核，Transaction 的流水、绑定、客户余额，Admin 的用户、团队、管理员、角色、审计。

  • 搜索始终存在，图标在输入内；只有明确帮助缩小范围的筛选才紧随搜索。
  • 桌面工具栏采用 40px 紧凑控件，搜索最大 28rem、普通筛选 10rem；筛选必须保留完整边框、文字和箭头，不得折叠成竖线或让选择箭头看似进入搜索框。移动端改为 44px 并逐项满宽排列。
  • 结果数量在末端，使用 aria-live；分页不是结果数量的替代品。
  • 移动端顺序固定为搜索、筛选、动作、数量，均占可用宽度。
  • 连续数据使用 .ls-list 或表格容器及细分隔线；通知、审核、主体目录不得逐项做悬浮卡片。
  • 列表 hover/focus 只使用表面色或可见焦点环，不改变边框粗细、不位移。

主体、状态与动作¶

主体统一用 LsEntityIdentity：真实头像优先；无图时按类型图标或首字回退；媒体位始终是圆角方形，同时显示类型、名称和 slug。直接描述该主体的状态使用组件 status 插槽紧随名称，不能作为独立网格列漂到整行末端；表格中用于跨行比较的状态才保留独立状态列。状态统一用 NTag，不得用页面私有胶囊。

列表行和主体卡片的桌面入口使用透明、无边框的图标加文字，不使用主色填充、浅色底或圆角按钮气泡；hover/pressed 只改变文字或图标状态，不形成新的胶囊轮廓。移动端仍采用“一个安全主操作 + 更多”，两者同样保持图标加文字的轻量入口外观和至少 44px 触控区。查看/管理通常是主操作，封禁、移出、删除不得成为移动端主操作。入口因权限或能力禁用时仍保持位置，并显示原因。表单提交、创建、确认和破坏性确认属于命令按钮，不受本条“入口”外观约束。

页面主内容或主集合的空数据和筛选无结果必须使用 LsEmptyState，且只传 title 与 description：标题说明当前没有什么，说明文本给出来源、边界或下一步；不得直接拼装裸图标、标题和段落，不得为单页扩展图标、动作、尺寸或样式参数。组件固定为白色有边界面板、Naive NEmpty 图标与居中排版，标准最小高度为 12rem、上下内边距为 2rem；禁止用 vw 或页面私有样式随桌面宽度继续拉高，仅在文案换行或文本放大确实需要时自然增高。桌面和移动端均须自然换行且不得横向溢出。创建等主操作保留在页面标题，不塞入空状态。消息时间线、详情卡片、表单候选区和统计小卡等局部区域不是“页面无数据”，继续使用与所在区域密度一致的紧凑说明；如需偏离，必须在应用规则登记原因。

同一顶栏中的链接、路由入口和 Naive UI 按钮使用完全相同的 --font-ui、14px 字号和 600 字重。NDropdown 等无根组件必须由真实 DOM 容器承担响应式显示类；验收时桌面不得同时出现完整动作和移动端“操作”按钮。

表单、上传与分页¶

表单默认单列，宽度不超过 form 容器；普通单控件字段必须使用 LsField，复杂联动、校验组或 Naive 表单验证使用 NFormItem，不得保留页面级 .field 标签皮肤。表单与局部操作错误使用只接收 message 的 LsInlineError；页面级异步加载和真实错误使用 LsAsyncState，两者不得互换或重复报告。同组提交与取消按钮同尺寸，并通过 LsButton 的 icon 插槽承载图标。上传必须使用 LsUploadField，按钮不得因“上传”语义单独放大。分页使用 NPagination；确需上一页/下一页模式时使用同尺寸 LsButton。

有边界的独立内容区统一使用无视觉参数的 LsPanel，标题、正文和页脚分别进入对应插槽；页面不得重新声明 .panel 的圆角、边框或内边距。连续表格、列表、弹层和确需不同语义根节点的表单不强行套用 LsPanel，但应使用 Naive UI 自有容器或公共列表边界。原生 <table> 只用于纯展示文档内容；后台数据表优先使用 NDataTable。Admin 用户、团队、管理员与审计页，以及 Transaction 流水、绑定、客户余额与余额明细页，已满足三页以上相同的响应式需求，统一使用 LsResponsiveDataTable；Team 客户目录复用这一既有模式。其他新模式不得仅为包一层 DOM 建组件，必须在 Wiki 登记达到相同复用阈值。

例外与检查¶

Admin 平台命令搜索是应用专属能力，可保留快捷键和弹层，但输入、结果行、移动布局和状态遵守公共组件。检查：在 320、375、768、1024、1440px 分别确认标题、工具栏、列表边界、操作层级与无横向溢出。
